# PAKO

Full accounting/finance platform for Kosovo SMEs and accounting firms. See `CLAUDE.md` for repo
layout and conventions, `docs/ARCHITECTURE.md` for the module design, `docs/ROADMAP.md` for the
build order.

Status: `Ledger` module built and tested (.NET/EF Core); `apps/web`, `apps/mobile`,
`packages/shared` are app-shell scaffolds; everything else is architecture only (as of
2026-08-26).
